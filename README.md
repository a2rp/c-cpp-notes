# C and C++ Study Notes

These are my personal study notes on C and C++, collected while learning programming fundamentals and working through small examples. They explain the language rules, memory model, standard library, and tools I want to remember when writing and reviewing programs.

## Scope and language versions

The examples use C17 and C++20 as practical baselines. Compiler and library support can vary, so check the selected compiler version when using newer language or library features. The notes focus on portable language behavior and call out cases where implementation details matter.

The chapters move from compilation and C fundamentals into pointers, files, modern C++, resource ownership, templates, containers, concurrency, testing, and debugging. The final chapters gather the code examples and review questions.

## How I use these notes

I keep these notes as a learning record and a reference for concepts I want to explain clearly. Read the chapters in order for a foundation, or jump directly to a topic when reviewing code. The examples are small enough to compile and inspect, with practice questions that encourage checking behavior rather than guessing.

Compiler diagnostics are part of the learning process. Build examples with warnings enabled, read the language and library references, and use sanitizers and a debugger when a program behaves unexpectedly.
